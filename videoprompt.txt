===================================
STATUS DEFINITIONS
===================================


1. LOCKED
------------

Meaning:
User cannot access this video yet.

Usage examples:
- Previous required episode not completed
- User does not have access permission
- Sequential learning restriction

Expected behavior:

Frontend:
- Show lock indicator
- Disable video playback
- Do not allow direct play

Backend:
- Prevent unauthorized playback token generation
- Do not create progress entry


-----------------------------------


2. NOT_STARTED
---------------

Meaning:
User has access but never started watching.

Condition:

Video available
AND
No watch progress exists

Initial state:

progress = 0%

currentPosition = 0

Frontend:

Show:
"Start Watching"

Do not show resume.


-----------------------------------


3. STARTED
-----------

Meaning:
User clicked play for the first time.

Trigger:

Video play event fired.

Expected:

When user starts video:

Create/update progress record:

status = STARTED

startedAt timestamp saved

Initial watch session begins.


Important:

Do not interfere with existing heartbeat logic.


-----------------------------------


4. IN_PROGRESS
---------------

Meaning:
User is actively watching but has not completed.

Conditions:

Video started

AND

Progress > 0%

AND

Completion criteria not reached


Use existing:
- heartbeat system
- progress calculation
- watch duration logic
- anti-cheat validation


Expected:

status = IN_PROGRESS

Store:
- last watched position
- percentage
- updated timestamp


Resume support:

When user returns:

Continue from last saved position.


-----------------------------------


5. COMPLETED
-------------

Meaning:
User has completed the video.

IMPORTANT:

Use the existing completion calculation.

Do not modify:

- percentage threshold
- duration checking
- watched segment validation
- cheat prevention


When existing system decides video completed:

Update:

status = COMPLETED

completedAt timestamp


Frontend:

Show:
Completed badge/checkmark


-----------------------------------


6. REWATCHING
--------------

Meaning:
User already completed the video and opens it again.

Condition:

Existing status = COMPLETED

AND

User plays video again


Expected:

Change current viewing state:

status = REWATCHING


Important:

Do NOT:

- Remove completedAt
- Reset progress percentage
- Reset watch history
- Affect course completion


Completion should remain permanently achieved.
