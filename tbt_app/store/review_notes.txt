PERMISSIONS DECLARED
--------------------

• Microphone (iOS + Android)
    Reason:  Required by the LiveKit SDK for workshop live-call attendee
             mode. Local mic is muted by default; users can toggle it
             from the call controls bar. Denying the permission is
             non-fatal — the user simply cannot un-mute.

• Notifications (iOS)
    Reason:  Push notifications for course access grants, batch-day
             approvals, live-call reminders, and admin announcements.
             We prompt for permission after login, never on cold start.

• Photo library / Files (iOS + Android)
    Reason:  Avatar upload and workshop assignment file submission.
             We use the system file picker; we do not read the library
             in the background.

No location, contacts, calendar, camera (photo capture), or Bluetooth
permissions are used.


IN-APP PURCHASE POSTURE
-----------------------

There are NO in-app purchases in this build. The "Upgrade" call-to-action
in the Products screen opens the TBT website in an external browser
(https://app.tamilbusinesstribe.com/Products) where members complete
purchase via bank transfer or Razorpay. This matches the guidance in
App Store Review Guideline 3.1.3(a) — "Reader" apps and services sold
outside of the app.
